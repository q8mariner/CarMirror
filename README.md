# مرآة السيارة (CarMirror)

يعرض شاشة الجوال كاملة على شاشة السيارة عبر Android Auto مع التحكم باللمس.

- البناء: يتم تلقائيًا عبر GitHub Actions، والملف يطلع تحت Artifacts باسم CarMirror-apk.
- الإعداد: فعّل "مصادر غير معروفة" في إعدادات المطوّر بـ Android Auto، واسمح بالإعدادات المقيّدة للتطبيق، وفعّل خدمة إمكانية الوصول.
- الاستخدام: شغّل البث من التطبيق (الشاشة بالكامل)، وبعدها افتح "مرآة السيارة" من شاشة السيارة.
